# 로또 번호 추천기

브라우저에서 **로또 번호(1~45) 6개를 중복 없이 랜덤 추천**해주는 간단한 웹사이트입니다.

## 실행 방법

- `index.html`을 더블클릭해서 브라우저로 여시면 됩니다.

또는 VS Code / Cursor에서 Live Server 같은 확장으로 실행해도 됩니다.

## 기능

- 1~45 중복 없는 6개 번호 추천
- 한 번에 5세트 생성(고정)
- 오름차순 정렬 또는 생성 순서 유지
- 오늘의 추천(매일 고정) 모드
- 보너스 번호(7번째) 포함
- 결과 복사
- 기록 저장/삭제 (LocalStorage)
